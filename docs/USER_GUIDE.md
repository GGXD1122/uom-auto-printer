# 使用说明

适用于 UOM自动打印 v1.2.56，Windows 10/11 x64。

## 1. 安装和打印准备

从 [Releases](https://github.com/GGXD1122/uom-auto-printer/releases/latest) 下载 `.exe` 安装包并安装。`Source code` 是源码压缩包，不是安装程序。无需自行配置 Python。

连接打印机，安装厂商提供的 Windows 驱动。进入软件的打印机设置，选择打印机和文件保存目录。打印预览上方选择与实际标签纸相同的尺寸，分别设置标签 1 和标签 2 的张数。两个标签共用一个纸张尺寸。

先导入一个有效实名码，检查预览，再点“立即打印”。尺寸不对时，检查 Windows 驱动中的纸张宽高、进纸方向和缩放设置。

## 2. 已有实名码怎么打印

在“自动打印”页点“导入实名码”，或把 PDF、JPG、PNG、BMP、WebP 文件拖入软件。识别成功后会更新标签预览。二维码模糊、遮挡或内容不支持时会显示错误，不能保证损坏的二维码都能恢复。

开启“导入后自动打印”后，成功导入会直接打印；关闭后可先看预览，再点“立即打印”。本应用没有独立的扫码枪输入框；需要输入飞机序列号时使用“信息查询”页。

打印时会在设置的输出主目录下创建 `姓名_电话_机型_序列号` 子文件夹，保存标签 PNG 和 PDF。只查询或预览不会向这个正式输出目录新增打印文件。

## 3. 新登记自动打印

在右侧 UOM 官网登录，然后切换“自动打印”页，点击“开启监听”。第一次读取用于记录当前已有设备，不会把所有历史登记打印一遍。

开启“新增登记自动打印”后，之后发现的新登记会按当前纸张和张数打印。“导入后自动打印”是另一个开关，两者互不代替。结束工作时点“停止监听”，或从托盘退出软件。

## 4. 改纸张和标签布局

在预览上方打开纸张列表，可滚动选择内置预设或个人预设。选中的打印模板会保存，下次打开仍沿用当前选择。

点“编辑”进入标签编辑器，切换标签 1/2，选择元素后调整位置、大小和旋转。二维码与其下方标识作为一组处理。通过“编辑尺寸”设置自定义宽高，允许范围为 10–200 mm；能设置这个尺寸不代表任意内容都能在小纸上清晰印出，应保留足够的二维码面积和文字间距。

点“保存”保存个人预设。保存模板与选择当前打印模板是两步：回到纸张列表选择新预设，确认预览正确后打印。未保存就返回时，按提示决定保存或放弃。

## 5. 查询设备

切换“信息查询”，输入飞机序列号并查询，或点“导入机身实名码”选择照片、截图或 PDF。查询成功后可复制信息；存在可生成标签的登记数据时可打印，并不要求设备一定属于当前登录账号。

如果公开查询返回打码电话，软件不会猜测完整号码。需要完整详情时，使用机身上的有效实名二维码。

## 6. 辅助实名登记

1. 在官网区域完成 UOM 登录。需要 DJI 查询时，切换大疆页面并登录。
2. 在“实名/注销”页的精准机型区域点击“更新”，获取本地型号库。首次没有预装型号数据；更新需要有效 UOM 登录，不需要提前扫脸。
3. 输入飞机序列号，拖入或点击选择整机照片、序列号照片。
4. 点击“识别并认证”，按提示完成 DJI 验证，取得对应机型名称。
5. 按弹窗提示用微信或支付宝完成 UOM 官方人脸验证。
6. 有多个型号候选时，核对型号代码、空机重量和最大起飞重量，选中后点“选好了”。
7. 软件准备好登记资料后，仔细核对最终确认窗口中的内容和照片，再确认提交。

成功后本次准备资料会清空，便于登记下一架。最终确认取消后，主按钮会进入可继续提交的状态。遇到无法继续的流程，可使用“重置”清理本次准备资料，登录状态和打印设置保留。

提交期间断网或官网无响应，可能出现“结果未知”。此时先到官网核对是否已经登记，不能直接当作失败重复提交。

## 7. 注销

“实名/注销”页面底部输入序列号或唯一识别码，再点“注销”。软件先核对当前账号的设备归属；属于本人且资料有效时弹出确认，否则提示无法注销。确认前核对设备信息。

## 8. 悬浮窗、关闭和升级

托盘菜单可显示或关闭悬浮窗，悬浮窗支持拖入文件。主窗口的叉号不等于完整退出；需要停止后台运行时，在系统托盘选择“退出程序”。

覆盖升级前先退出程序，再安装新版。不要自行删除应用数据目录，否则纸张选择、打印张数、个人预设和登录缓存可能丢失。

## 9. 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 找不到打印机 | 确认已安装 Windows 驱动，并能从系统设置中打印测试页 |
| 打印偏移或裁切 | 检查软件纸张尺寸与驱动纸张一致，再检查方向和可打印边距 |
| UOM 加载失败 | 检查网络、代理和系统时间，恢复连接后重新打开或刷新官网 |
| 人脸验证失败 | 按官方提示检查登录身份和认证渠道，必要时切换微信/支付宝 |
| 型号库更新失败 | 确认 UOM 已登录后重试；旧的完整型号库会保留 |
| 流程一直等待 | 等待超时提示，或重置本次流程；提交结果不明确时先查官网 |
| 安装时提示正在运行 | 从系统托盘退出程序后重试 |

反馈问题请附上软件版本、Windows 版本、发生步骤和错误提示。日志或截图中包含账号信息时，先移除不需要公开的内容。
